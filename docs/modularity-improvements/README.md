## Where the codebase stands

The package-level work is largely done, and it shows:

- **No package cycles.** `tests/unit/architecture/test_package_acyclicity.py` guards it.
- **Only 2 module-level cycles in 297 files** (`nodes._repair_loop <-> nodes.approval`,
  `mcp.contract <-> mcp.registry`).
- **Enola does not currently grade anything.** On clean HEAD it exits **3 (DECLINED)**:
  the pinned baseline was generated by enola `0.2.7-51-g72cd079` at `df97c47`; the
  installed enola is `0.4.25`, and the ignore globs differ. The required gate is
  blind until the baseline is regenerated — see [06 §6.9](06-small-ownership-fixes.md).
- **Two cross-package private-module reach-ins**, both recorded with reasons in
  `test_boundary_law.py`.
- Vocabulary (`filmspec`, `schemas`) sits at the bottom with fan-in 9 and 13 and
  fan-out ≤ 1; `storage`, `providers`, `checkpoints`, `kb`, and `config` are leaves or
  near-leaves.

So the next gains are **not** in the package import graph. They are in the places the
import graph cannot see: **how a request reaches the domain, how many layers
implement the same use case, and how many copies of the same lifecycle exist.**

## What this review does not recommend

- **No new layering law.** `06-independent-review-and-decision.md` §4 stands: the
  package table is an ownership map, not an import prohibition. Nothing here grades
  imports against `03-target-architecture.md`.
- **No DI container, no ports "for flexibility".** Every proposal below either deletes
  code or routes existing call sites through a mechanism that already exists
  (`MCPServer.call`, `StudioGraphState` annotations, `ToolContract`).
- **No `StudioRuntime` split yet.** `08` is still right that the consumer set must move
  first. Findings 01 and 03 *are* that consumer move; the split should be re-measured
  after them, not before.
- **No mass rename of the enum import path** (`schemas.base` re-exports `filmspec`
  enums; 274 imports use the alias vs 15 the owner). It is duplication of convenience
  under `00` §1.3 — two spellings of one object cannot diverge. Recorded in 06 as
  low priority only.

## Method

1. AST import graph over `src/film_pipeline` (eager, `TYPE_CHECKING`-excluded, and
   function-level imports tracked separately).
2. For each function-level import `A -> B`: does `B` reach `A` through eager imports
   (including package `__init__` execution)? If not, hoisting it cannot create a cycle.
3. Tarjan SCCs at module level for cycles the package guard cannot see.
4. Consumer counts for every public surface flagged as possibly orphaned.
5. Direct reading of the dispatch path, the graph-execution path, and the reducer
   declarations — the two correctness findings (01, 02) came from reading, then were
   confirmed by execution: [`probe_dispatch_paths.py`](probe_dispatch_paths.py) for 01,
   the graph-node identity check in 02.

What the method does **not** establish: that each recommended slice is
behaviour-preserving. Each document names the test that would prove it; no slice has
been implemented — this round changed no source, only added these documents, the two
scripts, and a `.gitignore` entry so the folder is tracked.
