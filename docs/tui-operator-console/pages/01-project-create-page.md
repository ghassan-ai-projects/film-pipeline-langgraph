# Project Create Page

## Purpose

Create a new project and enter the studio through an explicit onboarding surface.

## Primary Users

- studio_operator
- film_creator

## Why This Page Exists

Project creation is foundational and should not be hidden behind an undefined modal or
implied shell action.

This page owns:

- project identity setup
- runtime-mode choice
- workflow-mode choice
- profile-stack selection
- intake start

## Main Sections

### 1. Project Identity

Show/edit:

- title
- slug
- optional project id

### 2. Runtime And Workflow

Show/edit:

- runtime mode
- workflow mode
- explanation of each mode

### 3. Profile Stack

Show/edit:

- film type
- quality profile
- provider profile
- workflow/profile defaults summary

### 4. Policy And Readiness

Show:

- profile conflicts
- credential readiness
- workflow override allowance

### 5. Intake Launch

Actions:

- create project
- create and open project
- create and start intake

## Required Data

- profile catalog
- runtime readiness
- workflow-mode policy summary
- create-project result

## Cross-Links

- `Dashboard`
- `Project Settings`

High priority.
