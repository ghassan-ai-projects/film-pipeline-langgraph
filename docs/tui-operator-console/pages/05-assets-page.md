# Assets Page

## Purpose

Support reference images and other metadata-rich asset families.

## Primary Users

- film_creator
- studio_operator

## Why This Page Exists

Visual and metadata-heavy work needs its own navigation and enhancement flow.

## Main Sections

### 1. Asset Family Filter

Show:

- references
- character sheets
- environment boards
- shot rows
- prompt rows
- generation-plan rows

### 2. Asset List

Show:

- asset id
- asset type
- subject
- status
- issue count
- candidate vs approved indicator

### 3. Asset Detail Panel

Show:

- metadata
- provider info
- quality score
- approval history
- validation summary

### 4. Dependency/Usage Panel

Show:

- related scenes
- related shots
- dependent prompts
- downstream consumers

### 5. Asset Actions

Actions:

- request enhancement
- compare versions
- mark for review
- jump to related scene
- jump to related shot

## Key Actions

- navigate references and other assets
- inspect metadata deeply
- request targeted enhancement
- compare asset versions
- understand blast radius

## Required Data

- asset list by family
- asset detail
- asset issues
- asset usage/dependency summary
- asset comparison
- asset impact preview

- `Scenes`
