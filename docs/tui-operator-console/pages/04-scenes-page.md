# Scenes Page

## Purpose

Support scene-by-scene navigation and targeted scene improvement.

## Primary Users

- film_creator
- studio_operator

## Why This Page Exists

This page makes the TUI feel like a real story workstation.

It lets users work locally without losing wider context.

## Main Sections

### 1. Scene Navigator

Show:

- scene id
- heading
- dramatic function
- status
- issue count
- candidate vs approved indicator

### 2. Active Scene Reader

Show:

- heading
- action lines
- dialogue
- dramatic purpose

### 3. Scene Context Panel

Show:

- parent act
- related treatment intent
- character constraints
- environment constraints
- related shot links

### 4. Scene Issues

Show:

- scene-specific validation problems
- pacing notes
- continuity notes
- dialogue/tone notes

### 5. Scene Actions

Actions:

- request scene revision
- compare scene versions
- mark for later
- previous/next scene

## Key Actions

- navigate scene by scene
- request targeted scene improvement
- compare candidate and approved scenes
- jump to related assets
- jump to parent act in `Structure`

## Required Data

- scene list
- scene detail
- scene review workspace
- scene issue list
- scene comparison
- scene impact preview

## Cross-Links

- `Structure`
- `Review`
- `Assets`
- `Validation`
