# Project Settings Page

## Purpose

Support explicit project-level controls and inspectable project policy.

## Primary Users

- studio_operator
- film_creator

## Why This Page Exists

Workflow mode, profile defaults, and project-specific overrides must be explicit.

## Main Sections

### 1. Project Identity

Show:

- title
- slug
- runtime mode
- profile stack summary

### 2. Workflow Settings

Show:

- current workflow mode
- source of workflow mode
- whether override is allowed
- policy thresholds

### 3. Structural Intent

Show:

- target runtime
- film type
- other high-level project settings when available

## Key Actions

- change workflow mode
- inspect profile-derived defaults
- inspect why some settings are locked

## Required Data

- project identity summary
- workflow settings summary
- profile resolution summary

## Cross-Links

- `Dashboard`
- `Structure`

Medium priority.
