# Validation Page

## Purpose

Provide a focused view of validator output and issue resolution scope.

## Primary Users

- studio_operator
- film_creator

## Why This Page Exists

Validation should be readable as an actionable workspace, not just a report dump.

## Main Sections

### 1. Validation Summary

Show:

- report id
- blocking issue count
- warning count
- consensus state

### 2. Issue List

Show:

- issue severity
- issue scope
- validator source
- affected entity

### 3. Active Issue Detail

Show:

- explanation
- evidence
- linked artifact or scene
- recommended next action

## Key Actions

- inspect blocking issues
- jump to affected page
- filter by scope: structure, scene, asset, phase

## Required Data

- validation workspace
- issue list
- consensus explanation

## Cross-Links

- `Review`
- `Structure`
- `Scenes`
- `Assets`
