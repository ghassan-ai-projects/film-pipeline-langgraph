# Structure Page

## Purpose

Support project-level and act-level story shaping.

## Primary Users

- film_creator
- studio_operator

## Why This Page Exists

This is where the user inspects and changes strategic story shape.

It answers:

- is the film structurally working
- are the acts balanced
- is pacing healthy
- should duration increase or shrink

## Main Sections

### 1. Project Structure Summary

Show:

- target runtime
- estimated current runtime
- scene count
- act count
- structural health

### 2. Act Navigator

Show:

- act label
- duration
- scene count
- issue count
- pacing indicator

### 3. Active Act Detail

Show:

- act purpose
- scene sequence summary
- emotional progression
- entry/exit state

### 4. Structure Issues

Show:

- flow issues
- pacing issues
- setup/payoff issues
- duration imbalance

### 5. Structure Actions

Actions:

- validate flow
- request structural improvement
- increase duration
- reduce duration
- compare structure versions

## Key Actions

- inspect project-level flow
- inspect one act
- request act improvement
- request project duration increase
- jump to scenes in act

## Required Data

- project structure summary
- act list
- act detail
- structure validation report
- structure impact preview
