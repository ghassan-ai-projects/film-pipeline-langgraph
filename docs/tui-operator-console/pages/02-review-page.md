# Review Page

## Purpose

Support phase-level human decision-making.

## Primary Users

- studio_operator
- film_creator

## Why This Page Exists

This is where candidate work becomes approved, revised, escalated, or deferred.

The review page should feel like a decision workspace, not an artifact dump.

## Main Sections

### 1. Review Header

Show:

- phase under review
- workflow mode
- gate class
- recommendation
- decision status

### 2. Candidate Artifacts

Show:

- artifacts under review
- candidate refs
- approved baseline refs

### 3. Diff Summary

Show:

- what changed
- what stayed stable
- where risk increased

### 4. Validation Summary

Show:

- blocking issues
- warnings
- consensus disagreements

### 5. Decision Panel

Actions:

- approve
- request revision
- escalate
- defer

## Key Actions

- approve current phase
- request revision with notes
- jump to structure, scene, or asset scope
- inspect validation details
- compare candidate vs approved

## Required Data

- review workspace
- artifact diff summary
- validation summary
- workflow/gate decision explanation
- pending revision history
